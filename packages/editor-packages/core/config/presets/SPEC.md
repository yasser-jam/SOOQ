# SOOQ Blocks & Section Presets — Specification

Single source of truth for how page JSON is structured, which blocks exist, and how section presets are defined.

---

## 1. Data model

### SiteData (persisted in `localStorage` / `store_config.json`)

```json
{
  "root": { "props": { "title": "...", "bodyFont": "system" } },
  "zones": {},
  "pages": [
    {
      "path": "/",
      "slug": "/",
      "name": "Home",
      "link": "/",
      "content": []
    }
  ]
}
```

### Per-page Puck data (`UserData`)

```json
{
  "root": { "props": {} },
  "content": [],
  "zones": {}
}
```

### ComponentData (every block)

```json
{
  "type": "Section",
  "props": {
    "id": "Section-uuid",
    "name": "Hero",
    "content": []
  }
}
```

**Rules:**
- `type` must match a registered block in `config/index.tsx`.
- `props.id` is generated by the editor reducer (`populateIds` / `generateId`).
- Nested children live in **slot arrays** inside `props` (`content`, `items`, etc.) — not separate zone keys.
- Page root `content[]` typically contains only `Section` blocks.

### Hierarchy

```
SiteData.pages[].content[]
  └── Section (props.content[])
        ├── Group | Grid | Flex | Hero | Card | Content* ...
        └── Group.props.content[] → nested blocks
```

## 2. Container blocks

### Section (`type: "Section"`)

Page-level container. Renders a `<section>` with CSS grid for its slot.

| Prop | Type | Default | Notes |
|------|------|---------|-------|
| `name` | string | `"New Section"` | Outline label |
| `anchorId` | string | `""` | HTML `id` for in-page links |
| `visible` | boolean | `true` | Hidden on publish when `false` |
| `paddingTop` / `paddingBottom` / `paddingHorizontal` | string | spacing presets | |
| `backgroundColor` | string | `#ffffff` | Solid fill (ignored when `backgroundImage` set) |
| `backgroundImage` | string | `""` | URL; cover, centered |
| `backgroundOverlayColor` | string | `""` | rgba/hex/theme over image |
| `theme` | `"dark"` \| `"light"` | `"dark"` | Inherited text color |
| `maxWidth` | string | `1280px` | Inner container width |
| `columns` | number | `1` | Desktop grid columns (1–6) |
| `columnsMobile` | number | `1` | Grid columns ≤768px |
| `gridGap` | string | `24px` | Gap between grid cells |
| `content` | Slot | starter blocks | No nested `Section` |

### Group (`type: "Group"`)

Flex container. Can act as a **card** with surface styling.

| Prop | Type | Default | Notes |
|------|------|---------|-------|
| `direction` | `"row"` \| `"column"` | `"row"` | Flex direction |
| `gap` | number | `16` | px gap |
| `alignItems` | flex value | `stretch` | |
| `justifyContent` | flex value | `flex-start` | |
| `wrap` | `"wrap"` \| `"nowrap"` | `nowrap` | |
| `backgroundColor` | string | `""` | Theme token or hex/rgba |
| `padding` | string | `0px` | Inner padding |
| `borderRadius` | string | `theme-none` | Theme or px |
| `border` | string | `""` | e.g. `1px solid #e5e7eb` |
| `boxShadow` | `none` \| `sm` \| `md` \| `lg` | `none` | Shadow preset |
| `content` | Slot | paragraph | No `Section` |

### Grid (`type: "Grid"`)

| Prop | Type | Default |
|------|------|---------|
| `numColumns` | number | `4` |
| `gap` | number | `24` |
| `items` | Slot | starter content |

### Flex (`type: "Flex"`)

Same flex props as Group (without card surface fields). Uses `content` slot.

## 3. Content blocks (used in presets)

### ContentHeading

`text`, `textAlign`, `fontFamily`, `fontSize`, `fontWeight`, `lineHeight`, `color`, etc.

### ContentParagraph

Same typography props as heading.

### ContentImage

`src`, `alt`, `align`, `objectFit`, `radius`, `maxWidth`.

### ContentButton

`label`, `align`, `buttonVariantMode`, `buttonVariant` (`primary` \| `secondary` \| `error`), `link`, etc.

### Card

`title`, `description`, `icon` (lucide name), `mode` (`flat` \| `card`).

---

## 4. Layout (`WithLayout`)

Blocks wrapped with `withLayout` accept `layout` on `props`:

| Field | Purpose |
|-------|---------|
| `spanCol` | Grid column span inside parent Section/Grid |
| `spanRow` | Grid row span |
| `grow` | Flex grow inside Flex/Group parent |
| `paddingTop/Right/Bottom/Left` | Per-block padding |
| `borderWidth`, `borderStyle`, `borderColor` | Border |
| `shadowMode`, `shadowPreset` | Box shadow |
| `positionMode`, `floatPreset` | Floating placement |

When a block is a direct child of `Section`, `spanCol` max is **6**.

## 5. Section presets

Defined in `config/presets/index.ts`. Inserted via `insertPresetSection()` → Puck `insert` action.

### Categories

| Category | Status |
|----------|--------|
| `general` | 4 presets |
| `header` | empty (coming soon) |
| `footer` | empty (coming soon) |
| `products-grid` | Products grid, product card, product detail, **products page** presets |
| `account` | Profile, marketing preferences, saved addresses, add-address form (`customer-account` / `customer-addresses` section kinds) |

### Preset: `image-text-two-columns`

Two columns desktop, one on mobile. Image left; Group with heading, paragraph, primary button right.

```json
{
  "type": "Section",
  "props": {
    "name": "Image & text",
    "columns": 2,
    "columnsMobile": 1,
    "gridGap": "48px",
    "content": [
      { "type": "ContentImage", "props": { "objectFit": "cover" } },
      {
        "type": "Group",
        "props": {
          "direction": "column",
          "gap": 16,
          "content": [
            { "type": "ContentHeading", "props": { "text": "Your title here" } },
            { "type": "ContentParagraph", "props": { "text": "..." } },
            { "type": "ContentButton", "props": { "buttonVariant": "primary", "label": "Shop now" } }
          ]
        }
      }
    ]
  }
}
```

### Preset: `hero-background-image`

Full-width hero with background image, dark overlay, centered CTA.

```json
{
  "type": "Section",
  "props": {
    "columns": 1,
    "backgroundImage": "https://...",
    "backgroundOverlayColor": "rgba(0, 0, 0, 0.45)",
    "theme": "light",
    "paddingTop": "120px",
    "paddingBottom": "120px",
    "content": [
      {
        "type": "Group",
        "props": {
          "direction": "column",
          "alignItems": "center",
          "content": ["ContentHeading", "ContentParagraph", "ContentButton"]
        }
      }
    ]
  }
}
```

### Preset: `three-feature-cards`

Three `Card` blocks in a 3-column Section (`columnsMobile: 1`).

### Preset: `asymmetric-promo-cards`

4-column Section with two styled `Group` cards:
- Group 1: `layout.spanCol: 3`, `backgroundColor: "theme-primary"`, `padding: "40px"`, `borderRadius: "theme-lg"`, `boxShadow: "md"`
- Group 2: `layout.spanCol: 1`, `backgroundColor: "#f3f4f6"`, same padding/radius

## 6. Theme tokens

Colors: `theme-primary`, `theme-surface`, `theme-text`, etc. → CSS `var(--theme-*)`.

Typography: `theme-md`, `theme-lg`, `theme-bold`, etc.

Radius: `theme-sm`, `theme-md`, `theme-lg`, …

## 7. Editor UI

- **Active:** Shopify outline panel opens `config/plugins/shopify-editor/AddSectionModal`
  (section catalog presets, configure step for products grid, etc.).
- **Legacy (unreachable):** `plugins/blocks/AddSectionDialog.tsx` — old blocks-sidebar
  "Add section" dialog. Kept for reference; do not re-wire. Clicking a preset used to
  call `insertPresetSection()` on the root zone.
